# D2Coding

These font files are vendored from D2Coding VER1.3.3.

- Upstream: https://github.com/naver/d2-coding-font
- Release: https://github.com/naver/d2-coding-font/releases/tag/VER1.3.3
- Downloaded asset: `D2Coding-Ver1.3.3-20260725.zip`
- License: SIL Open Font License 1.1; see `LICENSE.txt`.

The Korean build uses D2Coding as the code/monospace font for both HTML and
PDF output. The release distributes TTF files, which are loaded directly by
the generated HTML and XeLaTeX build.
