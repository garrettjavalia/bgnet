# Yeomil Mono

These font files are vendored from Yeomil Mono v1.1.2.

- Upstream: https://github.com/taevel02/yeomil-mono
- Release: https://github.com/taevel02/yeomil-mono/releases/tag/v1.1.2
- License: SIL Open Font License 1.1

The Korean build uses Yeomil Mono as the code/monospace font for both HTML and PDF output. The files are vendored instead of loaded from a CDN because Yeomil Mono does not currently have the same mature CDN/package distribution story as Pretendard.
